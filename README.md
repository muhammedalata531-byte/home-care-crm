# HomeCare AI Copilot | مساعد حجز الرعاية المنزلية الذكي (نسخة المملكة العربية السعودية 🇸🇦) 🩺🎙️

> تطبيق ويب فائق السرعة والخفة لموظفي خدمة العملاء ومراكز الاتصال (Call Center Agents) في شركات الرعاية الصحية والطبية المنزلية بالمملكة العربية السعودية. يستمع لمحادثات المكالمات بالعامية السعودية مباشرة عبر الهاتف السحابي (VoIP / MicroSIP) **بشكل مستمر دون انقطاع أثناء فترات الصمت**، يستخرج بيانات الحجز الطبية واللوجستية بدقة عبر Google Gemini API، ويوفر زراً بنقرة واحدة لنسخ البيانات المهيكلة لنظام الـ CRM ورسائل تأكيد الواتساب مع طلب اللوكيشن.

---

## ✨ المميزات الرئيسية المحدثة (Saudi Arabia Edition)

1. **التقاط صوتي مستمر باللهجة السعودية (`ar-SA`)**:
   - **Continuous Stream Loop**: تسجيل مستمر لكامل المكالمة دون توقف عند فترات الصمت أو التردد أثناء الحديث.
   - **عداد مباشر لمدة المكالمة (Live Call Timer)**: يعرض وقت المكالمة الفعلي ثانية بثانية (`00:00`).
   - مؤشر موجات صوتية حي (Audio Wave Visualizer) يتفاعل مع طبقات الصوت.
   - تشغيل وإيقاف فوري عبر زر المايك أو بالضغط على زر **المسافة (Space)**.

2. **محرك استخراج البيانات الطبية بالذكاء الاصطناعي (Gemini AI Engine)**:
   - مخصص لمصطلحات ومدن ومناطق الرعاية الصحية في المملكة العربية السعودية (الرياض، جدة، الخبر، الدمام، مكة، المدينة...).
   - استخراج وتصنيف دقيق:
     - **اسم المريض / المتصل**: (الوالد أبو فهد، أم خالد، الأستاذ عبد الله الغامدي...)
     - **نوع الخدمة المطلوبة**: (تمريض منزلي | زيارة طبيب | إسعاف وطوارئ | علاج طبيعي | سحب عينات ومختبر | رعاية كبار السن | أشعة وفحوصات منزلية)
     - **المنطقة / الحي**: (الرياض - حي النرجس، جدة - حي الشاطئ، الخبر - حي الحزام الذهبي...)
     - **الموعد المقترح**: (اليوم بعد صلاة العصر، غداً 7:30 صباحاً صائم، عاجل وفوراً...)
     - **ملاحظات الحالة والطلب الطبي**: (غيار قرحة سكري، تأهيل حركي بعد جلطة، سحب تحاليل باقة شاملة، كشف باطنة...)
     - **درجة الفرز والاستعجال**: (عادي ✅ | عاجل ⚠️ | طوارئ قصوى 🚨)

3. **إجراءات الحافظة بنقرة واحدة (1-Click Actions)**:
   - **نسخ بيانات الحجز للـ CRM** (<kbd>Ctrl+Shift+C</kbd>):
     ```text
     الاسم: الوالد (كبير سن)
     الخدمة: تمريض منزلي
     المنطقة: الرياض - حي النرجس - شمال طريق أنس بن مالك
     الموعد: اليوم بعد صلاة العصر (4:30 - 5:00 عصراً)
     التفاصيل: مريض سكري وضغط طريح فراش، يحتاج تمريض منزلي متخصص للغيار على قرحة قدم سكري والتعقيم وقياس العلامات الحيوية.
     درجة الاستعجال: عادي
     ```
   - **نسخ رسالة تأكيد الواتساب السعودية** (<kbd>Ctrl+Shift+W</kbd>):
     ```text
     أهلاً بك في خدمة الرعاية الصحية والطبية المنزلية. تم تسجيل موعدكم مبدئياً (تمريض منزلي) في موعد: [اليوم بعد صلاة العصر].
     يرجى مشاركة الموقع الجغرافي الدقيق (اللوكيشن) عبر هذه المحادثة لتأكيد وصول الفريق الطبي في الموعد.
     نسعد بخدمتكم ونتمنى لكم دوام الصحة والعافية.
     ```

4. **محاكي المكالمات السعودية (Saudi Preset Scenarios)**:
   - 5 سيناريوهات مكالمات سعودية واقعية (الرياض، جدة، الخبر، الدمام) لاختبار النظام بضغطة زر.

## ⌨️ اختصارات لوحة المفاتيح (Keyboard Shortcuts)

| الاختصار | الوظيفة |
| :--- | :--- |
| <kbd>Space</kbd> | بدء / إنهاء تسجيل المكالمة الصوتية |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | استخراج وتحديث البيانات بالذكاء الاصطناعي (Gemini AI) |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | نسخ بيانات الحجز كاملة بصيغة الـ CRM |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> | نسخ رسالة تأكيد الواتساب السعودية |
| <kbd>Esc</kbd> | إغلاق النوافذ المنبثقة وسجل الحجوزات |
